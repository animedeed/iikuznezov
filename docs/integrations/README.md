# Контракты подключения ИИ-помощника руководителя

Контракты опираются на версию 1 типов основы. Каждый описывает вход и ответ канала, повтор и отказ, а также критерии подключения. Пометки о готовности сверены с коммитом основы `6fb5a92`.

| Направление | Что подключается |
| --- | --- |
| [Telegram](telegram.md) | Служебная карточка и решение пользователя, отображение состояния и плана |
| [Почта](mail.md) | Приём IMAP, маршрутизация по правилам и исходящая доставка |
| [Видеовстречи](meeting.md) | Сессия аватара, обмен репликами, завершение и финальная расшифровка |
| [Задачи](workflow-calendar.md#задачи) | Выдача поручений из утверждённого протокола, отображение сроков и статусов |
| [Календарь](workflow-calendar.md#календарь) | Проверка занятости, создание или перенос события, планы дня и недели |

Почта и встреча создают входы для общего сервиса. Telegram получает карточку сохранённой версии. После утверждения каждый деловой эффект получает собственный статус. Для автоматической почтовой маршрутизации требуется явное разрешающее правило профиля. Для утверждённого протокола рассылка, выдача полных поручений и согласованные записи календаря выполняются независимо.
